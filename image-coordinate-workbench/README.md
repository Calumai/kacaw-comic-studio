# image-coordinate-workbench

「圖像定位台」是一個本機優先的圖片標註工具。使用者把修改位置畫成點位、矩形或箭頭，工具會輸出原圖像素座標、0–1 比例座標、標註 PNG、定位 JSON，以及可直接貼給 AI 的修改工作單。

## 快速開始

### 直接開啟

雙擊 `index.html`。此模式不需安裝套件，也不會連線；若瀏覽器限制剪貼簿寫入，工具會改用相容的複製方式。

### 本機伺服器模式

雙擊 `啟動圖片定位製作台.cmd`，它會在本機啟動 `127.0.0.1:4173` 並開啟工具；若電腦找不到 Node.js，會自動退回直接開啟 `index.html`。

## 使用流程

1. 選擇、拖入或貼上 PNG、JPG、WebP。
2. 使用「點位」、「框選」或「箭頭」標出位置。
3. 為每個標註選擇操作：修改、移除並補背景、新增、移動或保留不動。
4. 填寫具體修改說明，必要時直接修改像素座標。
5. 在「輸出」頁籤確認 AI 修改工作單與全域保留規則。
6. 複製指令或匯出成果。

## 匯出成果

- `*-annotated.png`：原圖加上標註的光柵預覽。
- `*-anchor-overlay.png`：透明背景的光柵標註層。
- `*-anchors.json`：可重新匯入的定位專案，schema version 為 `1`。
- `*-ai-edit-instructions.txt`：包含原圖尺寸、座標規則、每筆修改與保留規則的 AI 工作單。

本工具不輸出 SVG。

## 座標規則

- 原點在原圖左上角，x 向右、y 向下。
- 原圖像素座標是唯一基準；縮放和平移只影響畫面，不改變標註資料。
- 矩形使用 `x, y, width, height`，右下邊界為 exclusive。
- 箭頭保存 `x1, y1, x2, y2`，並區分「指向目標」與「從起點移動到終點」。
- 比例座標以 0–1 表示，方便不同系統對照，但執行修改時仍以像素座標為準。

## 快捷鍵

| 功能 | 快捷鍵 |
| --- | --- |
| 選取／點位／框選／箭頭／平移 | `V`／`P`／`R`／`A`／`H` |
| 暫時平移 | 按住 `Space` |
| 復原／重做 | `Ctrl+Z`／`Ctrl+Y` |
| 刪除選取 | `Delete` 或 `Backspace` |
| 適合畫面／100% | `F`／`0` |
| 取消目前繪製 | `Esc` |

## 隱私與保存

- 圖片只在瀏覽器記憶體中處理，不會上傳。
- 瀏覽器只暫存定位文件與文字，不保存原圖；重新開啟後需再次掛載同尺寸圖片。
- 不使用 CDN、外部字型、分析服務、帳號或雲端儲存。
- 更換圖片前先匯出 JSON；載入不相符尺寸的圖片時不得默默套用舊座標。

```text
core.js                 座標、資料模型、工作單與歷史紀錄
app.js                  Canvas 互動、檔案處理與匯出
server.js               只綁定 127.0.0.1 的零相依靜態伺服器
啟動圖片定位製作台.cmd   Windows 雙擊入口
tests/core.test.js      核心邏輯測試
docs/                   AI 可讀的規格與工作紀錄
```
