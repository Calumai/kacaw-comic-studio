# Project Brief

## 目標

建立一個可快速指出「圖片哪裡要改、要改什麼」的本機製作台，讓非技術使用者不必手算座標，也能把精確、可重複執行的修改工作單交給 AI。

## 受眾

- 製作漫畫、教材、簡報、社群圖片與 UI 的創作者。
- 需要用座標向 Codex、ChatGPT 或其他圖像工具交辦修改的人。
- 不熟悉影像軟體，但需要精準溝通位置的使用者。

## 預計產出

- 可直接開啟的純靜態網頁工具。
- 點位、矩形、箭頭三種定位方式。
- 原圖像素與 0–1 比例座標。
- 帶標註 PNG、透明標註層 PNG、定位 JSON、AI 修改指令 TXT。
- 可重跑的測試與 AI 可讀專案文件。

## MVP 範圍

- 支援 PNG、JPG、WebP 單張圖片。
- 支援選檔、拖放與剪貼簿貼圖。
- 支援建立、選取、移動、調整、刪除、復原與重做標註。
- 支援操作類型、修改說明、箭頭語意及全域保留規則。
- 支援 JSON 匯入與瀏覽器暫存定位文件。

## 非目標

- 不直接呼叫生圖 API。
- 不編輯原圖像素、不提供完整 Photoshop 功能。
- 不做帳號、協作、雲端同步或素材庫。
- 不支援多頁專案、影片時間軸或向量 SVG 交付。

## 限制

- 本機處理，不得上傳圖片或依賴網路服務。
- 原圖不寫入 localStorage；恢復專案時需重新掛載圖片。
- 座標必須以原圖尺寸計算，不能以瀏覽器顯示尺寸代替。

## 成功標準

- 新手能在一分鐘內載圖、畫定位並複製 AI 工作單。
- 任意縮放或平移後，同一位置仍得到相同原圖座標。
- 匯出的 PNG 與原圖等尺寸，JSON 能可靠恢復定位。
- 另一個 AI 只讀文件與匯出成果即可接手修改，不必重問座標規則。
