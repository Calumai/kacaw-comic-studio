# Acceptance Criteria

## 啟動與隱私

- [ ] 雙擊 `index.html` 可使用主要功能。
- [x] `啟動圖片定位製作台.cmd` 只綁定 127.0.0.1，不對區網公開。
- [ ] Network 面板沒有圖片上傳、CDN、遙測或外部字型請求。
- [ ] localStorage 不包含原圖 Data URL 或 Blob。

## 載圖與畫布

- [ ] 可選擇、拖入、貼上 PNG、JPG、WebP；其他格式有明確提示。
- [x] 文件寬高跟隨每次匯入圖片的原始像素，不使用固定尺寸。
- [x] 小圖預設維持 100% 顯示，大圖才等比例縮小至工作區，圖片不變形。
- [ ] 顯示原圖尺寸、游標原圖座標與目前縮放。
- [ ] 適合畫面、100%、捲輪縮放與平移可用。
- [ ] 平移或縮放後，同一原圖位置的座標不變。

## 標註

- [ ] 可建立點位、矩形、箭頭並取得穩定 ID。
- [ ] 矩形反向拖曳會正規化，箭頭保留正確起訖方向。
- [ ] 可選取、移動、調整控制點、直接輸入座標與刪除。
- [ ] 標註不得被拖到圖片允許範圍之外。
- [ ] 可設定操作、修改說明、箭頭語意與全域保留規則。
- [ ] 復原、重做、Esc 取消與清除確認均正確。

## 座標與輸出

- [ ] 像素座標以原圖左上為原點，x 向右、y 向下。
- [ ] 矩形輸出 `x/y/width/height` 與 exclusive 的 `x2/y2`。
- [ ] 同時輸出 0–1 比例座標，數值由原圖尺寸計算。
- [ ] AI 工作單包含原圖尺寸、每筆操作／說明／座標與全域保留規則。
- [ ] 帶標註 PNG 與透明標註層 PNG 都和原圖等尺寸，且不是 SVG。
- [ ] JSON schema version 正確，可匯回並恢復全部標註。
- [ ] 圖片尺寸不符時不靜默套用舊定位。

## 品質與交接

- [ ] `node --check` 與核心單元測試全部通過。
- [ ] file:// 與 127.0.0.1 smoke test 均有結果紀錄。
- [ ] README、Architecture、Testing、Tasks、Decisions、Changelog 與專案卡已更新。
