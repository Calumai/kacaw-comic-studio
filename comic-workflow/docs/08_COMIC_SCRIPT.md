## 1. 這次真正的故事

小安第一次參加模擬測驗。他不是不會操作，而是太在意別人的進度，總覺得自己不能落後。

可愛的數位引導員 Kacaw 陪小安完成資料確認、登入與麥克風測試。小安因為急著跟上別人，第一次朗讀得太匆忙；停止錄音、等待系統自動儲存並播放後，聲音卻太小又模糊。

看到別人似乎已經完成測試，小安差點直接操作無關區域。Kacaw 及時擋住他，但沒有用魔法修好系統，而是提醒他停手、舉手。小安主動向老師說明狀況，在協助確認後重新錄音，這次用平常音量慢慢念清楚。

第二次依序停止、等待儲存、看到喇叭、播放確認後，小安終於聽見清楚的聲音。他也學會：準備階段不是比誰先按，先確認、再前進，反而比較不慌。

## 2. 戲劇核心

- 外在目標：正確登入，完成麥克風測試，依指示進入模擬測驗。
- 內在欲望：不要落後別人。
- 錯誤信念：只要按得快，就能跟上。
- 觸發事件：第一次播放聽不清楚。
- 錯誤選擇誘惑：不確認聲音，直接往下操作。
- 正確選擇：停手、舉手、接受協助、重新測試。
- 高潮：第二次播放傳出清楚的聲音。
- 角色成長：從「讓焦慮替自己按按鈕」變成「先確認，再自己決定下一步」。
- 主題：準備時，穩不是慢；穩是少走冤枉路。

## 3. Kacaw 的四個安心勾勾

這是漫畫角色使用的記憶法，不是官方清單：

1. 資料確認
2. 正確登入
3. 聲音清楚
4. 等到指示

準備卡仍必須補上：穩定網路、可收音的麥克風、安靜環境。正式操作與最終驗收仍以原講義為準。

3. 其他旁白稿或舊版手冊若與主要講義衝突，一律以主要講義為準。
4. Kacaw 是漫畫導覽角色，不暗示正式測驗網站真的會出現此角色。

## 5. 不可更改的操作因果

確認准考證號碼、登入密碼與測驗時間
→ 等老師或監考人員指示
→ 找到「進入測驗」
→ 輸入資料、檢查後登入
→ 找到錄音測試區
→ 點「錄音測試」
→ 照畫面文字，以平常音量慢慢念清楚
→ 點「錄音停止」
→ 等系統自動儲存
→ 喇叭圖示出現
→ 點喇叭播放並仔細聽
→ 異常則重錄或通知老師
→ 聲音清楚後仍等指示
→ 進入正式測驗，依題目指示作答。

## 7. 角色定位

### Kacaw

- 虛構 Q 版電腦娃娃數位引導員，不代表任何特定族別。
- 圓角螢幕頭、奶油色顯示面、簡單眼睛與嘴巴；青綠小機身、橘色狀態燈、短手短腳，約 2.3 頭身。
- 冷靜、有一點幽默，但不用嬰兒語，不嘲笑學生。
- 只負責提醒與阻止錯誤操作，不取代老師授權開始或處理故障。
- 不加入動物特徵、品牌標誌、文字、未經來源支持的頭飾、珠飾、傳統服裝或文化圖紋。

### 小安

- 第一次操作、有點在意進度的學生。
- 中性 Q 版造型，約 4 頭身；素色黃上衣、深藍下身。
- 犯錯源於壓力，不是笨；最後必須由自己做出「停手、舉手」的選擇。
- 不加入暗示特定族別的未經驗證文化標記。

### 老師／監考人員

- 多數時間以格外聲音、手部或側影出現。
- 是允許進入、允許開始與協助確認異常的權威。
- 不替學生輸入資料、不代答，也不演出來源未記載的進階設備維修。

- 敘事功能：確認權限後才操作。

- 敘事功能：小安主動放慢。

- 敘事功能：完成前兩個安心勾勾。

- 保護區：登入按鈕、游標與兩個亮起的圓章。
- 頁尾因果：小安第一次靠「確認」完成，而不是靠搶快。

- 保護區：嘴巴、麥克風、朗讀卡與波形。

#### P08-04｜照順序完成重錄

- 敘事功能：第二次仍完整遵循停止、儲存、喇叭、播放順序。

  1. 點「錄音停止」
  2. 系統自動儲存
  3. 喇叭圖示出現

## 9. 對話框與文字原則

- 生圖只產無字人物、無字場景與必要的無字介面底圖。
- 介面字、氣泡、尾巴、提示卡、擬聲與繁體中文以固定座標後製，正式試作輸出為 PNG，不使用 SVG。
- 第一輪樣張先不加入文化裝飾，避免支線干擾故事、操作與閱讀驗收。
- 每格以一個主要敘事功能為原則；P07-03 與 P09-03 因承擔轉折與餘韻，可有兩個短氣泡。
- 對話框先排入灰階分鏡，再依剩餘空間決定人物位置。
- 老師的格外氣泡尾巴接格框；Kacaw與小安的尾巴各自綁定嘴部錨點。
- 「進入測驗、登入、錄音測試、錄音停止、喇叭、波形、輸入欄」均為不可遮擋區。
- P06-03 必須完全無字；如果塞入解說，停頓即判定失敗。
- P07-03 是全篇最大動作格；P09-01 是全篇最大正向情緒格。

## 10. 故事與來源驗收

### 故事性

- 小安的問題源自壓力，不被畫成笨或不會操作。
- 錯誤誘惑、Kacaw 阻止、小安自己舉手必須分成三個節拍。
- 移除 P06 的停頓或 P08 的主動求助，故事均會失去因果，因此不可省略。
- 最後的成長是「比較不慌」，不是保證永遠不會卡住。

### 操作正確

- 公告包含准考證號碼、登入密碼和測驗時間。
- 老師指示在進入與正式開始之前出現。
- 兩次測試均可辨認：錄音、朗讀、停止、自動儲存、喇叭出現、播放確認。
- 異常處理是重錄或通知老師；仍不清楚可再次求助。
- 不出現真實或示意帳密、姓名、錯誤年份與虛構開始按鈕。

### 畫面可執行

- 每格都有景別、動作、文字預留與保護區。
- 重要文字可編輯，無生成亂字。
- 氣泡不超框、不互撞、不遮臉、不遮關鍵操作。
- 在手機尺寸不放大也能依左到右、上到下閱讀。
- 文化元素若沒有可追溯來源就不畫。
