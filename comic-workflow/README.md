# Mock Exam Video Project

這是一個「模擬測驗影片」製作專案資料夾。

目標是把測驗影片從想法整理成可執行流程，讓人類、Codex、Claude Code 或 ChatGPT 都能接手完成腳本、題目、分鏡、素材、配音與剪輯。

## Folder Map

- `docs/01_PROJECT_BRIEF.md`：專案目標、受眾、產出物與成功標準
- `docs/02_STYLE_GUIDE.md`：影片語氣、視覺、版面與禁忌
- `docs/03_WORKFLOW.md`：從規劃到輸出的完整流程
- `docs/04_ACCEPTANCE_CRITERIA.md`：完成條件與檢查清單
- `docs/05_TASKS.md`：可交辦給人類或 AI 的任務拆解
- `docs/06_DECISIONS.md`：重要決策紀錄
- `docs/07_PROMPTS.md`：可重複使用的 AI 指令
- `AGENTS.md`：給 Codex / Claude Code 的任務入口
- `ARCHITECTURE.md`：影片製作資料架構
- `TESTING.md`：驗證與檢查方式
- `CHANGELOG.md`：修改紀錄

## Current Assumptions

- 影片類型：模擬正式測驗流程的練習影片
- 受眾：學生、考生或課程學員
- 形式：題目畫面 + 倒數計時 + 答案解析
- 可替換內容：科目、年級、題型、題數、時間限制、視覺風格
