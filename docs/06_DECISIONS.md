# Decisions

| 日期 | 決策 | 原因 |
| --- | --- | --- |
| 2026-08-13 | 採純 HTML、CSS、JavaScript Canvas | 可直接開啟、無建置與雲端依賴 |
| 2026-08-13 | 原圖像素座標是 canonical；另輸出 0–1 normalized | 避免縮放造成歧義，同時方便跨系統對照 |
| 2026-08-13 | 原點左上，x 向右、y 向下；矩形右下為 exclusive | 對齊常見光柵影像與程式裁切規則 |
| 2026-08-13 | MVP 只做點位、矩形、箭頭 | 足以表達目標、範圍與移動方向，維持快速 |
| 2026-08-13 | 圖片不進 localStorage，只暫存定位文件 | 降低隱私與容量風險 |
| 2026-08-13 | 輸出 PNG、JSON、TXT，不輸出 SVG | 配合現有漫畫流程與可驗收光柵交付 |
| 2026-08-13 | 支援直接開啟，另提供只綁定 127.0.0.1 的 Windows launcher | 保留零安裝體驗並改善剪貼簿相容性 |
| 2026-08-13 | 不整合生圖 API | 工具只負責精準交辦，付費生成與修改留給外部流程 |
| 2026-08-13 | 顯示尺寸跟隨匯入圖片；小圖保持 100%，大圖才等比例縮小 | 避免不同小圖都被放大成近似固定大小，同時確保大圖仍可完整定位 |

## 固定資料規則

- schema version：`1`
- 標註 ID：`A01` 起，刪除後不重用。
- point：`x, y`
- rect：`x, y, width, height`
- arrow：`x1, y1, x2, y2`
- operation：`modify`、`remove_inpaint`、`add`、`move`、`preserve`
- arrowMeaning：`target` 或 `move`

## 待未來評估

- 多圖片／多頁專案。
- 圖層、自由筆刷、遮罩與多邊形。
- 自動擷取畫格或 OCR；不納入目前 MVP。
