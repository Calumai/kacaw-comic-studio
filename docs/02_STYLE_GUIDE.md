# Style Guide

## 體驗原則

- 像工具，不像聊天頁：操作狀態、座標與輸出要一直看得到。
- 先完成定位，再填說明；每一步都有立即回饋。
- 用白話繁體中文，不要求使用者理解 Canvas 或 normalized 等技術細節。

## 版面

- 上方：載圖、復原／重做、縮放與匯出。
- 左側：選取、點位、框選、箭頭、平移、刪除。
- 中央：圖片與 Canvas 標註舞台。
- 右側：標註清單、屬性檢查器與 AI 工作單。
- 下方：圖片狀態、游標座標、縮放與座標方向。

## 視覺

- 深色中性工作台，標註使用高對比暖色與有限輔助色。
- 目前選取、懸停、停用、錯誤與成功狀態必須可辨識。
- 不使用裝飾性背景、擬物陰影、AI 漸層或無功能動畫。
- 不使用外部字型、CDN 圖示或 SVG 輸出。

## 文字與命名

- 標註 ID 使用 `A01`、`A02` 連號；刪除後不重用。
- 按鈕使用動作名稱，例如「載入圖片」、「複製座標」、「下載 JSON」。
- 錯誤訊息說明發生什麼事與下一步，不只顯示「失敗」。

## 互動

- 捲輪以游標位置為中心縮放；Space 或 H 平移。
- 繪製中的圖形可用 Esc 取消。
- 清除全部與更換含標註圖片前要確認。
- 鍵盤焦點與停用狀態不得只靠顏色表示。
