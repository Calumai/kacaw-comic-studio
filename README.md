# 圖像定位製作台

用原圖像素座標精準標註漫畫中的對話框、UI、人物與留白區，並輸出可直接交給 AI 的修改指令。

## 內容

此 repository 本身就是圖像定位製作台：可載入 PNG/JPG、畫矩形／定位點／箭頭、輸入修改備註，並輸出 PNG 標註圖、JSON 座標與 AI 修改指令。

## 啟動定位製作台

直接雙擊：`啟動圖片定位製作台.cmd`

或在該資料夾執行：

```powershell
node server.js
```

再開啟 `http://127.0.0.1:4173/`。工具採原圖自然像素為唯一座標來源，原點在左上角，x 向右、y 向下；縮放和平移不會改變座標。

## 漫畫切換真實畫面

1. 載入漫畫底圖。
2. 用「框選」圈出漫畫中的螢幕區域。
3. 選取該矩形後，按上方「載入真實畫面」。
4. 用「漫畫畫面／顯示真實畫面」切換預覽。
5. 從匯出選單選「合成真實畫面 PNG」。

真實畫面只會套入選定矩形，人物、分鏡與其他區域保持不變；圖片仍只在本機瀏覽器處理。

## 隱私與檔案

控制台為 local-first，不會自動上傳圖片。請不要把個人資料、帳密或未選定的中間生成圖提交到 repository。
