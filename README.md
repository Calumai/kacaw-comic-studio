# Kacaw Comic Studio

這個專案把漫畫製作流程與圖像定位控制台放在一起，讓漫畫可以先用固定的分鏡與角色規則生成，再用像素座標精準修正對話框、UI、人物與留白區。

## 內容

- `comic-workflow/`：Kacaw 模擬測驗漫畫腳本、製作規則、測試紀錄與目前完成的 9 頁 PDF。
- `image-coordinate-workbench/`：離線圖片定位製作台。可載入 PNG/JPG、畫矩形／定位點／箭頭、輸入修改備註，並輸出 PNG 標註圖、JSON 座標與 AI 修改指令。

## 啟動定位製作台

直接雙擊：`image-coordinate-workbench/啟動圖片定位製作台.cmd`

或在該資料夾執行：

```powershell
node server.js
```

再開啟 `http://127.0.0.1:4173/`。工具採原圖自然像素為唯一座標來源，原點在左上角，x 向右、y 向下；縮放和平移不會改變座標。

## 漫畫製作邏輯

1. 先寫腳本與逐格驗收規則。
2. 生成「無文字、無對話框」的底圖，鎖定角色、場景、衣色與留白。
3. 用定位製作台標出要改的位置，輸出像素座標與 AI 修改指令。
4. 只修改標註範圍，重新驗收人物、構圖、UI 與流程因果。
5. 文字、對話框與流程卡以確定性後製完成，最後依頁序合成 PDF。

## 隱私與檔案

控制台為 local-first，不會自動上傳圖片。GitHub 只放製作程式、規格、腳本與已選定的交付 PDF；個人資料、帳密與未選定的中間生成圖不應提交。
